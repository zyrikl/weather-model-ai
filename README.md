# Weather model AI predictor
Weather predictor for Washington, DC based on previous years' data (1872 to 2025, taken from https://www.weather.gov/media/lwx/climate/dcatemps.pdf). Because I'm lazy, everything's in Fahrenheit. I'm hoping to teach the model through reinforcement learning. Really rudimentary, no dependencies needed.
## How to run
Run `./weather` after cloning the repo and building:
```bash
git clone "https://github.com/zyrikl/weather-model-ai"
make
./weather
```
